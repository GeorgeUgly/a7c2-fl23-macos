# 新版追加升级的受限快照收尾

此入口只处理 `upgrade` 已写入目标程序、完整读回通过，随后在 `upgrade_programs_written` 因当前设置 `chip0/0x02770015` 增加60而停止的情况。它不适用于首次安装、其他错误、已有WBI写入尝试或未知USB结果。旧版 `finish-install` 仍不支持新版组合。

2026-10-19，一次旧FL2/FL3到新版组合的真实追加升级已完成3处AP窗口写入及完整AP/CP读回；保存设置逐项未变，当前设置除原有允许的运行计数外，仅该字段增加60。工具按设计停止，正常返回MSC，未执行WBI写入。

随后经使用者明确选择，实际运行本入口的重新检查：完整程序读回及目标参数核验通过，但相对此前停止后的快照，该字段增加660，超过约定范围，因此在运行区域读取和WBI预检查之前停止。保存设置仍逐项相同，原状态文件未变，没有创建WBI写入尝试标记，正常返回MSC。两次快照相隔约658秒，与增量接近，但这种相关性不能证明字段含义。**字段含义尚未确认，默认入口不能扩大例外继续。**

使用者随后明确要求接受这一未知字段风险，才额外选择下文的有界时间例外。完整重新检查通过后，WBI预检查、固定 `image_drop=1 → image_mode=0` 及正常MSC返回均通过。真正取电池冷启动后，完整程序、目标参数和9处内存/磁盘区域核验通过，状态为 `verified_after_cold_start`。这只是一台机身的专项结果，不证明该字段无风险或其他停止点可同样处理；功能试拍、预设调出与录像仍需人工验证。

## 执行条件

必须保留原升级目录、原始备份、单次升级标记和全部私人证据。工具先离线核验唯一原生报告、真实完整读回文件、原错误和阶段、保存设置完全相同、历史字段恰好+60、其他差异只有原有允许的计数，以及未尝试WBI写入。不得修改状态或全局计数白名单来满足条件。

使用者了解上述未知字段风险和未实测边界，明确选择继续后，才可运行。相机须保持此次停止后的连接和供电状态，**不要先冷启动或重跑升级**。取得屏幕当前实际电量，至少50%。

```sh
sudo ./a7c2-mac finish-upgrade \
  --workspace "$HOME/Pictures/A7C2-upgrade" \
  --battery-percent ACTUAL_PERCENT \
  --accept-reviewed-upgrade-finish
```

工作目录须替换为原升级目录，电量替换为刚读取的实际数值。此命令会重新进入服务模式，读取完整目标程序、当前/保存/直接参数、7或9处运行区域和WBI状态。保存设置必须继续逐项一致；当前设置中的专项字段只接受相对停止后快照不变或恰好再+60，属性2且长度4字节；负向、其他增量或其他未允许字段变化全部停止。这个例外仅限本命令，不识别字段含义，不自动重试。

全部检查通过后，先保存独占的 `upgrade-finish-attempt.private.json` 标记，再运行固定上游WBI收尾。受限接口不允许安装器、追加升级器、AP/CP参数写入或保存设置命令。WBI本身会改变启动快照状态，存在设备操作风险。预检查失败不推进原状态；WBI开始后任何未知结果均保留单次标记并停止。

只有工具确认完成后才按提示正常关机、等存取灯灭、取电池约10秒再开机，随后对同一目录运行 `verify --cold-start-confirmed`。菜单、FL2/FL3拍摄回放、NTSC提示和M1–M4保存调出仍须人工实测。未确认完成时保持现状，不自动重跑或断电。

证据和摘要仅留本地，不上传原始程序、设置、机身身份或私人日志。

## 使用者明确选择的未知字段时间例外

默认限制保持不变。只有使用者已了解+660停止及字段含义仍未知，仍明确要求忽略该字段继续时，才可额外加入 `--accept-unconfirmed-live-time-field`。它只接受该当前字段不变，或增量为60的正倍数且与原快照至本次快照经过的秒数之差不超过120秒；参考时间必须在过去24小时内。字段属性2、长度4字节、其他字段限制、保存设置全等、全部程序和WBI检查仍生效，原历史差异仍必须恰好+60。

这一选择是对未知风险的明确接受，不是字段含义或安全性的证明；不用于首次安装或全局计数白名单。此前收尾检查必须全部有正常MSC返回、原状态未变、未尝试WBI的证据。没有WBI写入尝试标记也不能替代这些检查。
